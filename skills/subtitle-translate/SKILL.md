# Subtitle Translate — 中文字幕翻译

## 概述

将校对后的 `.en.srt` 逐条翻译为中文，存为同目录 `.zh.srt`。翻译后**仅列出需与用户商量的条目**，供用户确认与修正。

## 触发条件

- "把 <项目名>.en.srt 翻译成中文" / "生成 .zh.srt"
- 用户正处于工作流步骤 ④（翻译）

## 翻译目标

- 时间轴与英文**完全一致**
- 表达自然、贴合语境语气
- 术语/专有名词准确统一
- 仅列出需与用户商量的条目，供用户确认

## 格式与时间轴规则

- 保持 SRT 结构完全一致：编号、时间轴、文本、条目间空行
- **绝不改变英文时间**（每条 start/end 与 `.en.srt` 逐条相同）
- **不增删条目**（行数与英文一致 —— 双语合并的 index 对齐依赖它）
- 多行条目保持原有行数结构
- 可**调整语序**使中文自然，但不动时间

## 标点规则

| 位置 | 规则 |
|---|---|
| 行末 | **不加**逗号（，）、句号（。）、顿号（、） |
| 行末 | **保留**问号（？）、感叹号（！） |
| 句内 | **必须正常使用**标点：逗号（，）、顿号（、）、句号（。）等按中文习惯添加，**禁止用空格代替** |

> ⚠️ 易误解点：规则只约束「行末」，句内的停顿必须写标点。禁止为了省事把句内逗号/顿号删成空格。
> 正确示例：`还有敞开的窗户，让你能看到外面星盟战舰正在进攻`（句内逗号保留）；行末则无句号。

## 语境与语气

翻译前先判断：

- **视频类型**：游戏实况 / 科普讲解 / 剧情解说 / 技术演示 → 决定整体用词风格
- **原作者语气**：严肃专业 / 轻松口语 / 激昂热情 → 逐条斟酌用词
- 示例：
  - 技术讲解 → 用词专业、术语准确
  - 实况/闲聊 → 口语化、接地气
  - 保留角色/作者个性

## 术语与专有名词

- 既定译名全片统一，避免一物多名：
  - 角色/单位：士官长、斯巴达、凯斯、约翰逊
  - 载具/敌人：妖姬号、野猪兽、能量剑
  - 技术词：6 DOF=六自由度、motion controls=体感控制、frame generation=帧生成
  - 保留英文：DLSS、UNSC 等缩写、UEVR Nightly
- 拿不准的术语：查询确认后再译
- 无法确认的：在商量清单中**备注**标出，不擅自乱译

## 商量清单

- 译文直接写入 `.zh.srt`，**不逐条展示全部译文**
- 汇报时**只列出需要与用户商量的条目**（数量通常很少），以表格形式：
  - 拿不准的术语 / 专有名词译法
  - 语气、风格有歧义或需用户拍板的句子
  - 作者口语/句法特殊、译文拿捏不准处

```
## 需商量的条目：<项目名>
| 行号 | 英文原文 | 译文 | 待商量 |
|---|---|---|---|
| 3 | ... | ... | 术语：...；语气偏口语 |
```

- 常规、无歧义的条目不列出
- 用户确认/修正后，更新 `.zh.srt`

## 输出要求

- 文件名：`<项目名>.zh.srt`，与 `.en.srt` 同目录
- UTF-8 编码
- 格式与英文完全一致（含空行）

## 禁止事项

- ❌ 改变英文时间轴
- ❌ 增删字幕条目（行数必须一致）
- ❌ 行末加逗号/句号/顿号
- ❌ 句内用空格代替标点（句内必须正常使用逗号/顿号/句号）
- ❌ 机械直译（保留翻译腔）
- ❌ 术语不确认就乱译
